# Northlight Collective

A static portfolio page for introducing the members of an informal creative collective.

## Local preview

Open `index.html` in a browser.

## Render deployment

This project is configured as a Render static site through `render.yaml`.

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. In Render, create a new Blueprint from the repository.
3. Render will read `render.yaml` and deploy the static site from the project root.

## Legal positioning

The page copy intentionally describes Northlight Collective as an informal group of independent collaborators, not a registered company, partnership, or legal entity.
